# Public Website

The public-facing website for The Pillar Tabernacle Church.

## Current implementation

- Static HTML homepage and page shells.
- Shared CSS reset, design tokens, components and responsive rules.
- Vanilla JavaScript ES modules.
- Responsive navigation with keyboard dismissal.
- Basic page metadata and semantic landmarks.
- Placeholder notices wherever church-approved information is still missing.

## Local preview

Serve this directory using any static HTTP server. Because JavaScript uses native ES modules, do not open the pages directly with a `file://` URL.

## Important

The current brand styling is a provisional blue/white direction based on the project design notes. The official logo, final colours, church address, service times, leadership details, contact channels, media links and privacy notice still require church confirmation. No public form is connected to a backend yet.

Do not publish this site until all placeholders are resolved and the privacy/security review is complete.
