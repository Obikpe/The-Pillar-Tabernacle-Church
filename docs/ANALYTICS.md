# Analytics and Reporting

**Status:** Initial-release requirements

## 1. Purpose

Provide useful insight into public website engagement, visitor registration and church membership trends without creating unnecessary surveillance or exposing personal data.

## 2. Proposed measures

### Public website
- Aggregate page views.
- Aggregate unique/returning visit estimates, if the chosen analytics method supports them responsibly.
- Referrer/source categories.
- Visits to key pages such as services, events, livestream and sermons.
- Clicks on selected calls to action.
- Aggregate device category.
- Date-based trends.

### Registration and membership
- QR versus other registration source.
- New visitor submissions by period.
- Returning visitor submissions.
- New formal membership approvals by period.
- Pending review count.
- Follow-up completion and overdue counts.

### Definitions

Metric definitions must be documented. For example, a visitor registration submission is not the same as a confirmed in-person attendance, and an approved member count is not the same as a count of all contacts.

## 3. Privacy safeguards

- Prefer aggregate and event-level data without direct identifiers.
- Avoid collecting raw IP addresses unless strictly necessary and approved.
- Do not record prayer request text in analytics.
- Do not track sensitive form fields.
- Define retention periods.
- Restrict detailed analytics to authorised roles.
- Provide appropriate notices and consent where required.
- Consider a privacy-friendly analytics provider or minimal first-party event collection.

## 4. Initial implementation

Start with basic, privacy-conscious aggregate metrics. Do not build invasive tracking, fingerprinting or behavioural profiles. Avoid introducing a paid analytics service until the value and cost are established.

## 5. Reporting requirements

- Date range selection.
- Clearly labelled totals and trend charts.
- Definitions and source of each metric.
- Export only for roles with explicit permission.
- No fabricated data in production.
