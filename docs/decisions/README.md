# Architecture Decision Records (ADRs)

Use this folder to record significant technical decisions and why they were made.

Suggested filename: `NNNN-short-decision-title.md`.

Each ADR should contain:
- Status: Proposed, Accepted, Superseded or Rejected.
- Date.
- Context and problem.
- Decision.
- Alternatives considered.
- Consequences and follow-up work.

Do not use ADRs to silently change church policy. Membership, privacy and governance decisions must also be reflected in the requirements and policy documents.
